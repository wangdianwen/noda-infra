# Requirements: Noda 基础设施迁移到 iStoreOS (r4s) — v1.12 归档

**Defined:** 2026-05-17
**Shipped:** 2026-05-20
**Core Value:** 数据库永不丢失。迁移不改变核心功能，只改变运行位置。

## v1.12 Requirements

### 环境准备

- [x] **ENV-01**: r4s 上创建 Docker 独立网桥（noda-network），端口映射避免与软路由冲突
- [x] **ENV-02**: r4s 上创建 Swap 文件（建议 2GB）作为 OOM 缓冲，保护容器不被 kill
- [x] **ENV-03**: 所有容器配置内存限制（deploy.resources.limits），适配 r4s 3.77 GiB 内存
- [x] **ENV-04**: 配置 Mac ↔ r4s SSH 免密部署密钥（Jenkins 专用，非交互式）
- [x] **ENV-05**: 确认 iStoreOS Docker 开机自启已配置，容器 restart: unless-stopped 生效

**结果**: Phase 57 已完成，r4s 环境准备就绪。

### 基础设施迁移

- [x] **INFRA-01**: PostgreSQL 数据从 Mac 迁移到 r4s（pg_dump/pg_restore，零数据丢失）
- [x] **INFRA-02**: Keycloak 配置迁移到 r4s（realm/主题/客户端配置保持不变）
- [x] **INFRA-03**: Nginx 反向代理配置迁移到 r4s（upstream/SSL/路由规则保持不变）
- [x] **INFRA-04**: noda-ops 容器迁移到 r4s（Cloudflare Tunnel + 备份 + Doppler + supervisord）
- [x] **INFRA-05**: noda-network 外部网络在 r4s 上创建，所有服务加入同一网络

**结果**: Phase 58 完成，所有基础设施服务在 r4s 上正常运行。

### 应用迁移

- [x] **APP-01**: findclass-ssr prod 容器迁移到 r4s（构建仍在 Mac，镜像导出/导入到 r4s）
- [x] **APP-02**: findclass-ssr pre-prod 容器迁移到 r4s（共享 PostgreSQL/Keycloak 基础设施）
- [x] **APP-03**: noda-admin 管理后台迁移到 r4s
- [x] **APP-04**: noda-auth 认证应用迁移到 r4s

**结果**: Phase 59 完成，所有应用容器在 r4s 上正常运行。

### CI/CD 改造

- [x] **CICD-01**: Jenkinsfile 改造 — 本地 `docker compose` 命令改为通过 SSH 远程在 r4s 上执行
- [x] **CICD-02**: Docker 镜像构建流程调整 — Mac 构建镜像后通过 `docker save/load` 传输到 r4s
- [x] **CICD-03**: Jenkins SSH 远程部署 Pipeline 验证（构建 → 传输 → 部署 → 健康检查 → 完成）
- [x] **CICD-04**: 基础设施 Jenkins Pipeline（Jenkinsfile.infra）同步改造为 SSH 远程部署

**结果**: Phase 60 部分完成。基础设施部署 Pipeline 已改造并验证，应用部署 Pipeline 部分完成（noda-ops Jenkins 部署有残留问题）。

### 备份与 Cronjob 迁移

- [x] **BACKUP-01**: pg_dump 每日备份 cronjob 在 r4s noda-ops 容器中正常运行
- [x] **BACKUP-02**: B2 云备份上传从 r4s 正常执行（Cloudflare Tunnel 确保 B2 可达）
- [x] **BACKUP-03**: Doppler 密钥每日备份 cronjob 迁移到 r4s
- [x] **BACKUP-04**: 周验证测试 cronjob 迁移到 r4s
- [x] **BACKUP-05**: 旧 Mac 上的备份和 cronjob 清理确认

**结果**: Phase 61 完成，8/8 验证测试全部通过。

### 网络与域名

- [x] **NET-01**: Cloudflare Tunnel 从 Mac 迁移到 r4s，域名解析指向 r4s
- [x] **NET-02**: Nginx 端口映射（80/443）从 r4s 暴露，不与软路由端口冲突
- [x] **NET-03**: pre-prod 域名路由（pre.class.noda.co.nz 等）在 r4s Nginx 上正常工作

**结果**: Phase 61 完成，网络和域名迁移成功。

## Out of Scope（维持不变）

| Feature | Reason |
|---------|--------|
| r4s 上安装 Jenkins | 内存不够，Jenkins 留在 Mac |
| Docker Swarm/K8s | 单机部署，不需要编排工具 |
| 多架构镜像构建 | Mac M4 和 r4s 都是 ARM64，镜像直接复用 |
| iStoreOS 升级 | 不改变路由器固件版本，聚焦 Docker 迁移 |
| 数据库架构变更 | 只迁移位置，不改变数据库结构 |
