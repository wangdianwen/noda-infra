# Plan 62-01: 全链路 E2E 验证

## 目标

验证所有生产服务从浏览器到后端的完整链路，确认 r4s 迁移后用户不受影响。

## 前置条件

- Phase 61 已完成，所有 cronjob 和 Tunnel 在 r4s 运行
- r4s 所有容器处于 running/healthy 状态

## 任务

### T1: r4s 容器健康检查
- SSH 到 r4s 执行 `docker ps -a` 确认所有容器 running
- 逐一检查 health 状态：postgres, nginx, noda-ops, keycloak, noda-apps-prod, noda-apps-preprod
- 如有不健康容器，检查日志后重启

### T2: 生产域名 E2E 验证（外部访问）
通过 Mac 本地终端执行 curl，验证 Cloudflare → r4s 完整链路：

| 域名 | 预期 | 验证命令 |
|------|------|----------|
| class.noda.co.nz | HTTP 200 | `curl -sf -o /dev/null -w "%{http_code}" https://class.noda.co.nz/api/health` |
| auth.noda.co.nz | HTTP 307 (redirect to login) | `curl -sf -o /dev/null -w "%{http_code}" https://auth.noda.co.nz/` |
| www.noda.co.nz | HTTP 200 | `curl -sf -o /dev/null -w "%{http_code}" https://www.noda.co.nz/` |
| admin.noda.co.nz | HTTP 200 或 302 | `curl -sf -o /dev/null -w "%{http_code}" https://admin.noda.co.nz/` |

每个域名验证：
1. HTTP 状态码正确
2. 响应时间 < 5s
3. SSL 证书有效

### T3: Pre-prod 域名 E2E 验证
通过 /etc/hosts 直连 r4s:8443 验证：

| 域名 | 预期 | 验证命令 |
|------|------|----------|
| class.noda.test:8443 | HTTP 200 | `curl -k -sf -o /dev/null -w "%{http_code}" https://class.noda.test:8443/api/health` |
| auth.noda.test:8443 | HTTP 307 | `curl -k -sf -o /dev/null -w "%{http_code}" https://auth.noda.test:8443/` |
| www.noda.test:8443 | HTTP 200 | `curl -k -sf -o /dev/null -w "%{http_code}" https://www.noda.test:8443/` |
| admin.noda.test:8443 | HTTP 200 | `curl -k -sf -o /dev/null -w "%{http_code}" https://admin.noda.test:8443/` |

### T4: 关键用户流程验证
验证核心业务逻辑：

1. **Google OAuth 登录流程**: class.noda.co.nz → 点击登录 → Google OAuth → 回调 → 登录成功
   - 使用 Chrome DevTools MCP 跟踪完整 redirect chain
   - 确认 cookie domain 正确（.noda.co.nz）
2. **API 功能**: `curl https://class.noda.co.nz/api/health` 返回 JSON health status
3. **数据库读写**: 通过 API 验证数据库可读写（健康检查接口依赖数据库查询）

### T5: 备份系统运行验证
确认 r4s 上的备份系统仍在正常工作：

1. 手动触发一次 pg_dump 备份：`docker exec noda-ops /app/backup/backup-postgres.sh`
2. 验证备份文件出现在本地 + B2
3. 验证 Cloudflare Tunnel 仍然连接（外部域名可访问）

## 验证标准

- [ ] 所有 r4s 容器 running/healthy
- [ ] 4 个生产域名返回正确 HTTP 状态码
- [ ] 4 个 pre-prod 域名返回正确 HTTP 状态码
- [ ] Google OAuth 登录流程完整通过
- [ ] 备份系统正常运行

## 回退

如果验证失败：
- 记录具体失败点和错误信息
- 不进行任何清理操作
- 创建 debug session 调查
