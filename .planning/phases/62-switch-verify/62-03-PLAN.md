# Plan 62-03: Mac 旧容器清理

## 目标

清理 Mac 上不再需要的 Docker 容器、镜像和卷，释放资源。回滚方案已在 Plan 62-02 中验证。

## 前置条件

- Plan 62-01 全链路验证通过（r4s 生产正常）
- Plan 62-02 回滚方案已验证（回滚能力确认）

## 任务

### T1: Mac Docker 状态盘点
列出 Mac 上所有 Docker 资源：

1. **运行中容器**: `docker ps -a` — 列出所有容器及状态
2. **Docker 镜像**: `docker images` — 列出所有镜像及大小
3. **Docker 卷**: `docker volume ls` — 列出所有卷
4. **Docker 网络**: `docker network ls` — 列出所有网络
5. **磁盘占用**: `docker system df`

### T2: 清理决策
根据盘点结果分类：

**保留（Jenkins + 回滚依赖）：**
- Jenkins 相关容器/镜像
- noda-network 外部网络（回滚需要）
- docker/.env（密钥，回滚需要）
- 部署脚本（紧急回退入口）
- 关键基础镜像（postgres, nginx, keycloak — 回滚需要）

**可清理：**
- 已停止的 noda-ops 容器（Phase 61-03 已确认清理）
- 已停止的应用容器（findclass-ssr, noda-apps 等）
- 悬空镜像（dangling images）
- 未使用的卷（非 postgres_data）
- docker-compose.simple.yml 相关的旧容器/镜像

### T3: 执行清理
按优先级执行：

1. **停止并删除已停止的容器**: `docker rm $(docker ps -aq -f status=exited)`
2. **清理悬空镜像**: `docker image prune -f`
3. **清理未使用卷**: `docker volume prune -f`（注意排除 postgres_data）
4. **清理未使用网络**: `docker network prune -f`（注意排除 noda-network）
5. **最终磁盘报告**: `docker system df`

### T4: 清理后验证
确认清理没有影响 r4s 生产：

1. **r4s 服务正常**: SSH 到 r4s 检查所有容器 running
2. **外部访问正常**: curl 验证 class.noda.co.nz 返回 200
3. **Jenkins 可用**: curl 验证 http://localhost:8888 返回 200
4. **回滚能力保留**: 确认保留的镜像/网络/密钥仍然存在

## 验证标准

- [ ] Mac Docker 盘点报告已记录
- [ ] 不必要的容器/镜像已清理
- [ ] 磁盘空间已释放（对比清理前后）
- [ ] r4s 生产服务不受影响
- [ ] Jenkins 正常运行
- [ ] 回滚依赖资源保留

## 安全约束

- **不删除 postgres_data 卷** — 生产数据唯一副本现在在 r4s，但 Mac 副本作为额外保险暂时保留
- **不删除 noda-network** — 回滚需要
- **不删除 docker/.env** — 包含所有密钥
- **不删除部署脚本** — 紧急回退入口
- **不删除关键基础镜像** — postgres, nginx, keycloak（回滚需要约 2GB）
