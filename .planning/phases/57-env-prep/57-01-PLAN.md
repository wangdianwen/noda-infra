<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mac (Jenkins) -> r4s (SSH) | SSH 密钥认证通道，Jenkins 通过 ed25519 密钥免密登录 |
| r4s jenkins 用户 -> Docker socket | docker 组权限，可管理容器但不能 sudo |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-57-01 | Elevation of Privilege | jenkins 用户 docker 组 | mitigate | jenkins 仅加入 docker 组，不配置 sudo 权限（per D-24） |
| T-57-02 | Tampering | SSH authorized_keys | mitigate | authorized_keys 仅添加 Jenkins 公钥，文件权限 600，owner 为 jenkins（per D-27） |
| T-57-03 | Information Disclosure | Swap 文件内容 | accept | Swap 内容为内核管理，vm.swappiness=10 减少使用频率；物理访问才可读取，r4s 为受控设备（per D-22） |
| T-57-04 | Denial of Service | 内存资源耗尽 | mitigate | 2GB Swap 缓冲 + 所有容器内存限制（per D-10），确保 OOM 时内核杀死容器而非整机崩溃 |
</threat_model>
