<read_first>
- scripts/backup/lib/config.sh（全文，重点第 38-75 行）
</read_first>

<action>

第 72 行：`B2_ACCOUNT_ID="${DEFAULT_B2_ACCOUNT_ID}"` 改为 `B2_ACCOUNT_ID="${B2_ACCOUNT_ID:-${DEFAULT_B2_ACCOUNT_ID}}"`

## Task 2: 配置 DOPPLER_TOKEN 环境变量

<read_first>
- docker/.env（全文，确认 DOPPLER_TOKEN 行不存在）
- docker/docker-compose.yml（第 93 行：`DOPPLER_TOKEN: ${DOPPLER_TOKEN}`）
</read_first>

<action>
1. 在 Mac 上运行 `doppler configs tokens create noda-ops-backup --project noda --config prd --access read` 获取 DOPPLER_TOKEN
2. 在 `docker/.env` 文件末尾（`DOPPLER_PROJECT=noda` 行附近）添加：
   ```
   DOPPLER_TOKEN=<从步骤 1 获取的 token 值>
   ```
3. 将更新后的 .env 文件同步到 r4s：`scp -i ~/.ssh/id_noda_r4s docker/.env root@192.168.100.1:/path/to/noda-infra/docker/.env`
4. 在 r4s 上重建 noda-ops 容器使环境变量生效：
   ```bash
   ssh -i ~/.ssh/id_noda_r4s root@192.168.100.1 'cd /path/to/noda-infra && docker compose -f docker/docker-compose.yml -f docker/docker-compose.prod.yml -f docker/docker-compose.r4s.yml up -d --force-recreate noda-ops'
   ```

**注意：** 步骤 1 需要开发者手动执行（需要 Doppler CLI 登录），标记为非自动化步骤。
</action>

<acceptance_criteria>
- `docker/.env` 包含 `DOPPLER_TOKEN=` 且值非空
- r4s 上 `ssh -i ~/.ssh/id_noda_r4s root@192.168.100.1 'docker exec noda-ops env | grep DOPPLER_TOKEN'` 返回非空值
- noda-ops 容器健康状态为 `healthy`：`ssh -i ~/.ssh/id_noda_r4s root@192.168.100.1 'docker inspect --format="{{.State.Health.Status}}" noda-ops'`
